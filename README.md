# Hand Cricket Game

This is an Odd-Even game, also known as Hand Cricket, made purely using Java and runs in the terminal.

## IT IS FINALLY READY TO USE!

To use this game, you need to install JDK from the Oracle website and install it on your system.

Then download both:
- `Main.java`
- `RUN_GAME.bat`

Make sure both files are in the same directory.

After that, double-click on `RUN_GAME.bat` and the game will start running.
